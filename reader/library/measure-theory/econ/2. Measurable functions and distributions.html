2. Measurable functions and distributions

Models compute functions, not sets: assets as a function of the household, consumption as a function of the state, output as a function of the history of shocks. This chapter says which functions are compatible with a σ-algebra, what it means for a function to be “known” given some information, and how a function carries a measure from one space to another. The last idea is how a population of labelled households becomes a wealth distribution, which is the object heterogeneous-agent models actually work with.

Throughout, $(\Omega, \mathcal{F})$ is a measurable space from Chapter 1, and functions take real values unless said otherwise.

2.1 Preimages

Let $X : \Omega \to \mathbb{R}$ be a function and $B \subseteq \mathbb{R}$ a set of values. The preimage of $B$ is

$$ X^{-1}(B) = \{\omega \in \Omega : X(\omega) \in B\}, $$

the set of points that $X$ sends into $B$. The notation $X^{-1}$ does not require $X$ to have an inverse. It is defined for every function, and it is a set, not a point. Probabilists abbreviate it as $\{X \in B\}$, so $\{X \leq c\}$ means $\{\omega : X(\omega) \leq c\}$.

Preimages behave perfectly with respect to set operations:

$$ X^{-1}(B^c) = \bigl(X^{-1}(B)\bigr)^c, \qquad X^{-1}\Bigl(\bigcup_n B_n\Bigr) = \bigcup_n X^{-1}(B_n), \qquad X^{-1}\Bigl(\bigcap_n B_n\Bigr) = \bigcap_n X^{-1}(B_n). $$

Each identity is a restatement of a sentence. “$X(\omega)$ is not in $B$” is “$\omega$ is not in the preimage of $B$.” “$X(\omega)$ is in some $B_n$” is “$\omega$ is in some preimage.” Preimages of disjoint sets are disjoint, since a point cannot be sent to two places. These facts drive everything below.

2.2 Measurable functions and random variables

Definition. $X : \Omega \to \mathbb{R}$ is measurable (with respect to $\mathcal{F}$) if $X^{-1}(B) \in \mathcal{F}$ for every Borel set $B \subseteq \mathbb{R}$. A random variable is a measurable function on a probability space.

Measurability is what lets us ask about a function using the measure. If $X$ is measurable, every question of the form “what is the probability that $X$ lies in $B$?” or “what fraction of households have $X$ in $B$?” refers to a set that has a size.

Checking every Borel set would be hopeless. One family suffices:

Proposition. $X$ is measurable as soon as $\{X \leq c\} \in \mathcal{F}$ for every real $c$.

Why. Consider the collection of all sets $B \subseteq \mathbb{R}$ whose preimage is in $\mathcal{F}$. By the identities of Section 2.1 and the axioms for $\mathcal{F}$, this collection is closed under complements and countable unions, and it contains $\mathbb{R}$. So it is a σ-algebra. By assumption it contains every half-line $(-\infty, c]$. The half-lines generate the Borel σ-algebra, because $(a, b] = (-\infty, b] \setminus (-\infty, a]$. A σ-algebra containing the generators contains everything they generate, so it contains every Borel set. ∎

This argument, “the sets with the good property form a σ-algebra, and it contains a generating family,” is the standard way of proving anything about all measurable sets at once. It will be used again without comment.

Now the information reading. If $\mathcal{G}$ represents what an agent knows, then $X$ is $\mathcal{G}$-measurable when, for every threshold $c$, the agent can tell whether $X \leq c$. Knowing the answer to every threshold question is knowing the value of $X$. So:

$X$ is $\mathcal{G}$-measurable means that someone with information $\mathcal{G}$ knows the value of $X$.

In the coin example of Chapter 1, let $Y = 1$ if the first toss is a head and $0$ otherwise, and let $X$ be the total number of heads. $Y$ is $\mathcal{F}_1$-measurable: its preimages are among $\varnothing$, $\{HH, HT\}$, $\{TH, TT\}$, $\Omega$. $X$ is not: $\{X = 1\} = \{HT, TH\}$ is not in $\mathcal{F}_1$. After one toss, you know $Y$ but not $X$. Both are $\mathcal{F}_2$-measurable.

Measurability is easy to keep once you have it. If $X$, $Y$ and $X_1, X_2, \ldots$ are measurable, then so are

  • $X + Y$, $XY$, $\max(X, Y)$, $\min(X, Y)$, and $g(X)$ for every continuous (or Borel) function $g$, such as $u(X)$ for a utility function $u$;
  • $\sup_n X_n$, $\inf_n X_n$, and $\lim_n X_n$ wherever the limit exists.

The second item is where σ-algebras earn their countable axioms. For instance $\{\sup_n X_n \leq c\} = \bigcap_n \{X_n \leq c\}$, a countable intersection of measurable sets. Value functions computed by iteration are limits of measurable functions and so are measurable. In practice nothing an economist builds from measurable inputs, using formulas, limits, maxima over countable sets, and continuous functions, fails to be measurable. Measurability is the price of admission, and the closure properties guarantee you never have to pay it twice.

One case needs care: a maximum over an uncountable set, such as $v(x) = \max_{y \in \Gamma(x)} F(x, y)$ with a continuum of choices $y$. Continuity usually rescues it (a continuous objective on a compact choice set gives a continuous, hence measurable, maximum), and Chapter 6 returns to it.

2.3 The information carried by a variable

Every random variable $X$ defines its own σ-algebra,

$$ \sigma(X) = \{X^{-1}(B) : B \text{ Borel}\}, $$

the events that can be decided by looking at $X$ alone. It is the smallest σ-algebra for which $X$ is measurable: the information revealed by observing $X$. For several variables, $\sigma(X_1, \ldots, X_n)$ is the σ-algebra generated by all of their preimages, the information in observing all of them.

When does knowing $X$ tell you $Y$? The answer is the most useful single fact in this chapter for an economist.

Theorem (Doob–Dynkin lemma). $Y$ is $\sigma(X)$-measurable if and only if $Y = g(X)$ for some Borel function $g$. The same holds with $X$ a vector $(X_1, \ldots, X_n)$ and $g : \mathbb{R}^n \to \mathbb{R}$.

One direction is the closure property above. The other says that a variable decided by the information in $X$ is literally a function of $X$. Consider a household whose state is assets and productivity, $(a_t, z_t)$. The statement “savings $a_{t+1}$ depend only on the current state” means $a_{t+1}$ is $\sigma(a_t, z_t)$-measurable. By the lemma that is the same as $a_{t+1} = g(a_t, z_t)$ for some function $g$, the policy function. Recursive macroeconomics is the decision to look for decisions of this form, and the lemma is the guarantee that nothing is lost by writing them as functions of the state.

2.4 Distributions as pushforwards

Let $(\Omega, \mathcal{F}, \mu)$ be a measure space and $X$ measurable. Define a measure on the real line by

$$ \mu_X(B) = \mu\bigl(X^{-1}(B)\bigr) = \mu(X \in B), \qquad B \text{ Borel}. $$

To size a set $B$ of values, pull it back to $\Omega$ and measure it there. This is a measure: $\mu_X(\varnothing) = 0$, and if $B_1, B_2, \ldots$ are disjoint, their preimages are disjoint with union $X^{-1}\bigl(\bigcup B_n\bigr)$, so countable additivity carries over. $\mu_X$ is the distribution (or law) of $X$, also called the pushforward of $\mu$ by $X$ and written $\mu \circ X^{-1}$. When $\mu = P$ is a probability, $\mu_X$ is a probability measure on $\mathbb{R}$, and by Section 1.6 it is determined by its distribution function $F_X(x) = P(X \leq x)$.

Take the population $\Omega = [0, 1]$ with Lebesgue measure $\lambda$ and an asset function $a(i)$. The pushforward $\Psi = \lambda \circ a^{-1}$ is the wealth distribution: $\Psi(B)$ is the fraction of households whose assets lie in $B$. Figure 2.2 draws this. Two things are lost in passing from $a$ to $\Psi$: which household holds which wealth, and the ordering of households along $[0,1]$. Relabel the households in any measure-preserving way and $\Psi$ is unchanged. Macro models with a continuum of anonymous households need only $\Psi$, because prices depend on aggregates, aggregates are averages over households, and (Chapter 3) averages over households can be computed from $\Psi$ alone. That is why the state variable of an incomplete-markets economy is a distribution over individual states, not a list of individuals.

Vectors work the same way. If $X = (X_1, \ldots, X_n)$, its distribution is a measure on $\mathbb{R}^n$, called the joint distribution. The distribution of households over assets and productivity is a measure $\Psi$ on pairs $(a, z)$, and $\Psi(A \times Z)$ is the fraction of households with assets in $A$ and productivity in $Z$.

Independence. Random variables $X$ and $Y$ are independent if

$$ P(X \in A,\ Y \in B) = P(X \in A)\, P(Y \in B) \qquad \text{for all Borel } A, B. $$

In the language of σ-algebras: every event in $\sigma(X)$ is independent of every event in $\sigma(Y)$. Learning anything about $X$ tells you nothing about $Y$. Equivalently, the joint distribution of $(X, Y)$ is the product measure $\mu_X \otimes \mu_Y$, which is defined in Chapter 3. A sequence of shocks $\varepsilon_1, \varepsilon_2, \ldots$ is i.i.d. (independent and identically distributed) if any finitely many of them are independent and all have the same distribution.

That such a sequence exists on some probability space is not obvious, because a history is an infinite object. It is guaranteed by the Kolmogorov extension theorem: probabilities specified consistently for every finite stretch of history extend to a unique probability measure on the space of infinite histories, with the σ-algebra generated by events that depend on finitely many dates. Every infinite-horizon stochastic macro model rests on this theorem, usually without mentioning it.

2.5 Simple functions

The integral will be built from the simplest measurable functions. A simple function is a finite combination of indicators of measurable sets,

$$ \varphi = \sum_{k=1}^{m} c_k\, \mathbf{1}_{A_k}, \qquad c_k \in \mathbb{R},\ A_k \in \mathcal{F}. $$

It takes finitely many values, and each value is taken on a measurable set. A step function on an interval is a simple function, but so is $\mathbf{1}_{\mathbb{Q}}$, the indicator of the rationals, which jumps everywhere. Simple functions care about the sets on which values are taken, not about whether those sets are intervals.

Proposition. Every measurable $f \geq 0$ is the limit of an increasing sequence of simple functions $0 \leq \varphi_1 \leq \varphi_2 \leq \cdots$, with $\varphi_n(\omega) \to f(\omega)$ at every $\omega$.

A formula does it: round $f$ down to the nearest multiple of $2^{-n}$, and cap the result at $n$,

$$ \varphi_n(\omega) = \min\Bigl(n,\ 2^{-n} \bigl\lfloor 2^n f(\omega) \bigr\rfloor\Bigr), $$

where $\lfloor y \rfloor$ is the largest integer at most $y$. Each $\varphi_n$ takes finitely many values, the sets where it takes each one are preimages of intervals under $f$ and so are measurable, refining the grid from $2^{-n}$ to $2^{-n-1}$ never lowers the rounded value, and at any $\omega$ with $f(\omega) \lt n$ the error is less than $2^{-n}$.

The grid in Figure 2.3 is a grid of values. The horizontal axis is never cut into pieces. That is the idea behind the integral of the next chapter, and the reason it works on spaces, like a set of histories, that have no horizontal axis to cut.
