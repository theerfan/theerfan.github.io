# Interpretability

Reading notes on mechanistic interpretability papers: what each one claims, who wrote it, and where to read it.

> These are pointers and short quotes, not copies. Each paper stays on its authors' site, and the links below go there. Neither page carries a reuse licence, so this library keeps attribution, the abstract, and the outline, and sends you to the original for the full text and its interactive figures. The Reader Android app also keeps a personal offline copy of each paper, under *offline/* in this library.

## Papers

- <a href="Neural%20Networks%20Are%20Already%20Clean.md"><strong>Neural Networks Are Already Clean</strong></a>
  - Nick Cammarata (Goodfire), October 2026. Argues that most neurons are already legible, and that the classic evidence for superposition was misread. <a href="https://already-clean.goodfire.com/">Original</a>
- <a href="Natural%20Language%20Autoencoders.md"><strong>Natural Language Autoencoders Produce Unsupervised Explanations of LLM Activations</strong></a>
  - Fraser-Taliente, Kantamneni, Ong et al. (Anthropic), May 2026. Trains a model to describe its own activations in words, and checks the descriptions by rebuilding the activations from them. <a href="https://transformer-circuits.pub/2026/nla/index.html">Original</a>
